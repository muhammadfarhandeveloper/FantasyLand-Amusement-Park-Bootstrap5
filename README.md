# Fantasy Land Amusement Park Website

A fully responsive multi-page amusement park website built using **HTML5**, **CSS3**, and **Bootstrap 5**.

This project showcases a modern UI design for a fantasy/amusement park including ticket booking pages, restaurant section, gallery, login/signup system UI, and contact pages.

---

## Features

- Responsive Design
- Bootstrap 5 Layout
- Multi-Page Website
- Modern UI/UX
- Image Gallery
- Ticket Booking Page
- Restaurant Section
- Login & Signup Pages
- Contact Form
- Mobile Friendly Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
